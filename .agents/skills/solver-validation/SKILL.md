# Solver Validation Protocol

This skill enforces independent verification of every solution generated by any solver in Ising Engine.

## Non-Negotiable Invariants

1. **Zero Trust in Self-Reported Metrics**:
   - Never accept an objective value, energy, or constraint satisfaction flag reported by the solver itself.
   - The solver binary may have tracking bugs, arithmetic overflows, or cache desynchronizations.
   - All candidate states must pass through an independent verification function that shares no mutable state, buffers, or computational shortcuts with the solver hot path.

2. **Maximum Independent Set (MIS) Verification**:
   - Given a returned binary assignment $x \in \{0, 1\}^N$ or vertex set $V' = \{v \mid x_v = 1\}$:
     1. **Edge Collision Check**:
        For every edge $(u, v) \in E$, verify:
        $$\neg (u \in V' \land v \in V')$$
        If any edge has both endpoints in $V'$, mark the solution as **INFEASIBLE / INVALID**.
     2. **Independent Cardinality Count**:
        $$|V'| = \sum_{v \in V} \mathbb{I}(v \in V')$$
     3. **Comparison**:
        Verify that reported $|V'|$ matches the independent count exactly.

3. **QUBO / HUBO Energy Verification**:
   - Independent energy recalculation:
     $$E(x) = \sum_i h_i x_i + \sum_{i < j} J_{ij} x_i x_j + \sum_{i < j < k} K_{ijk} x_i x_j x_k + \dots$$
   - Must be computed directly in high-precision `f64` from the raw instance matrix/edge list, never using the solver's incremental delta arrays.
   - Tolerance check:
     $$|E_{\text{solver}} - E_{\text{recalculated}}| < 10^{-9}$$
   - Any divergence greater than float epsilon indicates an internal delta-energy bug and is treated as a critical test failure.
