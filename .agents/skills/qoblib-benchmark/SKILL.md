# QOBLIB Benchmark Protocol

This skill governs all benchmarking, validation, and submission preparation using the Quantum Optimization Benchmarking Library (QOBLIB 2026, Nature Computational Science, ZIB-AOPT / IBM Quantum Working Group).

## Pre-Benchmark Requirements

1. **Upstream Source Pinning**:
   - Upstream repository: `https://github.com/ZIB-AOPT/QOBLIB` (or official mirror).
   - Before executing any benchmark, run `git fetch` and record:
     - Exact upstream repository URL;
     - Exact commit SHA-256 hash;
     - Benchmark suite release tag / version;
     - Instance filename and MD5/SHA256 checksum;
     - Official optimal or best-known value (BKV) from the official `best_known_solutions.csv`.

2. **Official Solution Verifiers**:
   - Always compile and run the official ZIB checker for the problem class (e.g., `check_stableset` for Class 07, `check_labs` for Class 02, `check_marketsplit` for Class 01).
   - Never trust an objective value or feasibility flag generated by our own solver.
   - A solution is only counted as valid if the official checker exits with code 0 and reports `VALID: Solution successfully verified`.

## Specific Class Protocols

### Class 07 — Maximum Independent Set (07-independentset)
- **Feasibility Verification**:
  - For candidate vertex set $V' \subseteq V$, verify that for every edge $(u, v) \in E$, it is **NOT** the case that both $u \in V'$ and $v \in V'$ (0 collisions).
- **Objective Calculation**:
  - Recalculate $|V'|$ independently by counting included vertices.
- **Reporting Metrics**:
  - Feasibility (valid/invalid);
  - Cardinality $|V'|$;
  - Gap to official BKV / exact optimum: $|V'| - \alpha(G)$;
  - Time-to-best (seconds of CPU wall-clock);
  - Time-to-solution (TTS with 99% confidence);
  - Success rate across $\ge 10$ independent random seeds;
  - Explicit timeout threshold.

### Class 01 — Market Split (01-marketsplit)
- Formulate as exact quadratic equality $\min \sum_k (\sum_j A_{kj} x_j - b_k)^2$.
- Verify 0 equality constraint violations using `check_marketsplit`.

### Class 02 — Low Autocorrelation Binary Sequences (02-labs)
- Compute exact autocorrelations $C_d = \sum_{i=0}^{N-1-d} s_i s_{i+d}$ from scratch.
- Verify energy $E = \sum_{d=1}^{N-1} C_d^2$ with `check_labs`.
- Never claim a world record unless $E < E_{\text{BKV}}$ and confirmed by `check_labs`.
