# Ising Engine

High-performance Ising / QUBO / HUBO solver written in Rust.

## Features

- Multi-Spin Coding
- Parallel Tempering
- Population Annealing
- HUBO (2/3/4-body)
- SIMD-first architecture
- High-performance Monte Carlo
- Axum HTTP API
- Criterion benchmarks

## Build

cargo build --release

## Test

cargo test --release

## Benchmark

cargo bench
